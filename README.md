## 🌟 Imkoniyatlar va Funksiyalar

1. **📖 3D Interaktiv Flipbook:**
   * Haqiqiy qog'oz jurnal shaklida varaqlanadigan yuqori sifatli elektron katalog.
   * Sahifalar bo'yicha tezkor navigatsiya va mundarija.

2. **📦 To'liq Mahsulotlar Katalogi:**
   * Shampunlar (aktiv ko'pik, qo'l yuvish, nanoshampunlar: 1L, 5kg, 20kg va aromalar).
   * Antifrizlar (-40°C ko'k, qizil: 1kg, 5kg, 10kg va katta hajmlar).
   * Professional quritish sochiqlari (Microfiber & Plush GUFF tolalari).
   * Avtomobil polik qog'ozlari («УДАЧИ НА ДОРОГЕ», 500 dona).
   * Qidiruv va toifalar bo'yicha saralash.

3. **🛒 Savat va Telegram Orqali Buyurtma:**
   * Mahsulot hajmi va miqdorini tanlash.
   * Yetkazib berish hududini tanlash.
   * Telegram orqali mas'ul savdo vakiliga 1 bosishda to'liq chek bilan buyurtma yuborish.

4. **📞 Hududiy Savdo Vakillari Tizimi:**
   * O'zbekistonning barcha tuman va viloyatlari bo'yicha mas'ul savdo vakillari ro'yxati.
   * To'g'ridan-to'g'ri qo'ng'iroq va Telegram tugmalari.

5. **🛡️ Administrator Boshqaruv Paneli:**
   * Narxlarni real vaqt rejimida boshqarish va yangilash.
   * Narxlarni ommaga ko'rsatish yoki yashirish (obrazets rejimi).
   * Savdo vakillari va hududlarni biriktirish.
   * Tushgan barcha zayavkalar va Telegram buyurtmalari statistikasi.

## 🚀 GitHub Pages Orqali Saytni Ishga Tushirish

1. Ushbu loyihani o'zingizning GitHub hisobingizga yuklang (`git push`).
2. GitHub-dagi repozitoriy sozlamalariga kiring: **Settings** ➔ **Pages**.
3. **Build and deployment** bo'limida:
   * **Source:** `Deploy from a branch`
   * **Branch:** `main` (yoki `master`) / `/ (root)`
4. **Save** tugmasini bosing.
5. 1-2 daqiqada sizning global saytingiz havola orqali ochiladi:
   `https://<sizning-github-nomingiz>.github.io/<repo-nomi>/`
